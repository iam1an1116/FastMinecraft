# FastMinecraft 桌面级前端 UI 重构设计规范

## 1. 目标与视觉哲学
将 FastMinecraft 的前端彻底重构为纯正、高质感的现代桌面级应用。
- **App 外框大 R 角**：应用整体最外层容器采用超大圆角（`rounded-[24px]`），提供类似原生 macOS / Windows 沉浸式浮动窗口质感。
- **无黑线条边框、去卡片方框化**：完全消除粗硬或深色的线条边框，取消一个个方形带框卡片的拼凑感，改用留白、通透背景与微妙的灰白层级划分区域。
- **磨砂玻璃 Header**：`backdrop-blur-xl bg-white/70`，无 Logo，原生交通灯留白与拖拽支持。
- **零解释型冗余文字**：去除无意义的段落说明与帮助文字，纯功能组件化。

---

## 2. 角色分流体系 (Role State Machine)

- **初次打开引导 (Onboarding)**：
  - 检查 `localStorage.getItem('fm_role')`。
  - 若无记录，居中呈现无硬框、圆润的身份选择视图：
    - `【我是服主】` (host)
    - `【我是玩家】` (player)
  - 选中后持久化存储并进入对应模式。
- **Header 模式切换胶囊**：
  - Header 右侧常驻极简圆润胶囊，显示当前身份，点击可随时自由切换【服主 / 玩家】模式。

---

## 3. 导航与页面架构

### 3.1 磨砂玻璃 Header（无 Logo）
- **左侧**：保留 macOS 红绿灯窗口控制区安全边距（`pl-20`）。
- **主导航组**：
  - **`[ 控制台 ]` / `[ ← 返回 ]`**：
    - 在服务器列表状态下显示为 `[ 控制台 ]`。
    - 进入特定服务器后，原按钮动态变为 `[ ← 返回 ]`，点击退回服务器列表。
  - **`[ 市场 ]`**：各类 Minecraft 服务端（Paper / Purpur / Fabric / Forge / NeoForge / Vanilla）一键下载部署，以及上传本地 jar 部署。
  - **`[ 联机 ]`**：本地 LAN、公网 IPv6、P2P 隧道三大模式的管理面板。
  - **`[ 设置 ]`**：全局 Java 管理、系统设置。
- **右侧**：
  - `[ 服主 / 玩家 ]` 模式切换胶囊。

### 3.2 服主模式：二级菜单与内容排布
- 当点击某服务器进入详情后：
  - 主 Header 的“控制台”变为“← 返回”。
  - 同时在 Header 中或正下方展开二级圆润胶囊菜单：
    - `[ 控制台 ]`（实时日志流、命令输入、快捷指令、性能状态指标）
    - `[ 玩家 ]`（在线玩家、OP、踢出、封禁）
    - `[ Mod ]`（Mod/插件列表、开关、上传）
    - `[ 备份 ]`（备份创建、恢复、管理）
    - `[ 配置 ]`（server.properties 可视化调整）

### 3.3 玩家模式 (Player Mode)
- 纯粹专为加入他人服务器的玩家打造：
  - 大圆角输入框：直接粘贴 P2P 房间码。
  - `[ 连接 ]` 按钮。
  - 本地代理状态展示（`127.0.0.1:25565` 就绪状态与延迟 Ping）。
  - 辅助入口：局域网发现与 IPv6 直连。

---

## 4. 样式与组件规范
- 背景：`bg-neutral-50` 或纯白 `#FFFFFF`，外框 `rounded-[24px]`，溢出隐藏 `overflow-hidden`。
- 按钮：`rounded-full` 或 `rounded-2xl`，微阴影，无生硬黑线边框。
- 输入框：`rounded-2xl bg-neutral-100/70 border-0 focus:ring-2 focus:ring-black/10`。
